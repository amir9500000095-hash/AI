# AI — مرکز پروژه‌های هوش مصنوعی

این مخزن مرکز پروژه‌ها، ابزارها و آزمایش‌های هوش مصنوعی و نرم‌افزار است. یکی از پوشه‌های برنامه‌ای فعلی، نمونهٔ اندرویدی مستقل **همدل‌پت** است.

## همدل‌پت (Hamdel Pet)

یک نمونهٔ بومی Android با Kotlin، رابط فارسی و تمرکز بر دسترس‌پذیری صفحه‌خوان‌ها.

- کنترل‌های غذا دادن، تمیز کردن، بازی و خواب
- نگهداری وضعیت سادهٔ حیوانک روی دستگاه
- دکمه‌های بومی Android با نام‌های قابل خواندن برای TalkBack
- پیام‌های وضعیت پس از هر کنش
- تصویر حیوانک اختصاصی که با Canvas بومی Android رسم می‌شود؛ از تصویر یا گرافیک Pou استفاده نمی‌کند
- صفحهٔ «دربارهٔ ما» با پیوندهای قابل انتخاب با صفحه‌خوان، بدون استفاده از HTML
- ساخت APK آزمایشی با GitHub Actions

### ساخت و دریافت APK

1. [باز کردن GitHub Actions](https://github.com/amir9500000095-hash/AI/actions)
2. انتخاب آخرین اجرای موفق **Build Hamdel Pet APK**
3. در بخش Artifacts، دریافت `hamdel-pet-debug-apk`
4. فایل ZIP را باز و APK داخل آن را نصب کن.

APK با کلید debug اندروید امضا می‌شود و برای آزمایش است؛ این امضا گواهی انتشار Google Play یا اثبات هویت ناشر نیست. برای انتشار رسمی باید کلید انتشار جداگانه و امنی مدیریت شود.

## رابطه با Pou

Pou یک بازی تجاری مستقل است که این پروژه را الهام‌بخش توجه به دسترس‌پذیری کرده است. **همدل‌پت نسخهٔ اصلاح‌شده یا بازسازی کامل Pou نیست**، به سازندهٔ آن وابستگی ندارد و از منابع تصویری یا صوتی اختصاصی آن در نمونهٔ فعلی استفاده نمی‌کند. APK ارائه‌شده برای بررسی، بستهٔ کامپایل‌شده است و به‌تنهایی کد منبع اصلی بازی را در اختیار نمی‌گذارد. بنابراین هنوز نمی‌توان ادعا کرد تمام قابلیت‌ها، ظاهر یا صداهای بازی اصلی حفظ شده‌اند.

## آزمایش دسترس‌پذیری

TalkBack را روشن کن و نام و ترتیب پیمایش همهٔ دکمه‌ها را بررسی کن. پس از هر کنش، پیام وضعیت باید خوانده شود. این نمونه هنوز روی دستگاه فیزیکی با TalkBack به‌طور کامل تأیید نشده؛ گزارش‌های کاربران برای تکمیل آزمون لازم‌اند.

برای گزارش مشکل، نسخهٔ Android، صفحه‌خوان و مراحل بازتولید را بنویس. اطلاعات خصوصی، رمز یا دادهٔ حساس را در Issues عمومی قرار نده.
